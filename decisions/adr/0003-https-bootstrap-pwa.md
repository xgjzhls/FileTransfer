# ADR-0003: HTTPS 引导 + PWA 离线安装

- 状态：已接受（待确认「每设备可联网一次」）
- 日期：2024-08-13

## 背景
- ADR-0002 需要摄像头扫码 → getUserMedia 要求页面为安全上下文
- 局域网 `http://192.168.x.x` 不是安全上下文（非 localhost 的明文 HTTP 不满足）
- 关键事实：https 源 + Service Worker 缓存 → 离线打开时 URL 仍是 https 源 → 仍是安全上下文，摄像头权限可用

## 决策
PWA 部署在 HTTPS 静态托管（GitHub Pages / Cloudflare Pages，免费）；每台设备联网访问一次、添加到主屏幕、SW 缓存全部资源；此后永久离线使用（含摄像头扫码）。

## 后果
- 正面：一次引导换永久离线；零运行时服务；用户无感
- 负面：
  - 每台设备需要一次联网引导；**空气隔离网络**（完全无互联网）需要备用路线：电脑本地 HTTPS + 自签 CA 证书安装信任（iOS 对 IP SAN / `.local` 证书支持存在已知问题，体验差，不建议默认）
  - 摄像头权限在引导时授予，离线后是否持续有效需要验证（列入 spike）
