  • 冷启动：不点下方按钮，直接到卡片 3 建连 → 记录是否成功 + 报错原文 + 是否自动弹权限窗
  • 先授权：点下方按钮触发系统权限弹窗（允许）→ 再建连 → 记录是否成功

4 · 数据面：延迟 / 吞吐 / 内存 / 后台

通道打开后可用。吞吐 = 本机 → 对端（64 KiB/块 + 背压），对端统计实际字节与耗时。接收端若发现收包间隙 > 2s 会标红（后台/锁屏挂起信号）。内存峰值：Chrome 自动采样；WKWebView 无 performance.memory → 请配合 Xcode 内存仪表观察。

（跑吞吐时若方便：把 app 切到后台 5 秒再回来，观察对端日志是否出现「收包间隙」）
