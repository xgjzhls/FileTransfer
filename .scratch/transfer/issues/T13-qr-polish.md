## 目标
离线兜底更顺：接收端免选角色直接扫码（码型判定自动进入流程）；扫码失败自动重试、提示清晰；配对成功明确反馈。不做中等/大改项（信任设备记忆、配对向导重设计）。

## 验收标准（done when）
- [x] 接收端不再需要先点「我是接收端」：直接进入扫码，识别到 offer 码自动走 answer 流程（发送端仍需先「显示配对码」——offer 必须先于 answer 存在，这是方向性约束）
- [x] 扫码失败（解码失败 / 码型与当前角色不符）→ 明确提示 + 自动恢复可重扫，不卡死、不需手动重置
- [x] 错误文案按场景区分：权限拒绝（含 HTTPS 提示）/ 无摄像头 / 摄像头占用 / 非安全上下文（沿用 T07 `cameraErrorText` 分类，补齐缺漏场景）
- [x] 配对成功明确反馈（保留现有「配对成功」提示与自动收起行为；QR 连接归属门控——在线连接完成时不误报）
- [x] 测试：单测（自动角色判定逻辑）+ e2e（接收端直接扫码路径）全量跑绿
