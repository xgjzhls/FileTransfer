# T06: UI 双区块 + 可见性开关（ADR-0006 修订落地）

- 状态：待实现
- 阻塞：T02, T03, T05
- 被阻塞者：T09
- 引用：ADR-0009 决策 2/6；SPEC §6；ADR-0006 修订

## 目标
设备列表分「在线房间」「局域网发现」两区块；设置页「局域网可见性」开关（默认开）；ADR-0006 可见性门控修订的 UI 落地。

## 验收标准（done when）
1. 两区块并存：在线房间设备（现有，PIN 门控语义不变）+ 局域网发现设备（来源标注「局域网」）；信令不可达（离线）时自动聚焦局域网区块
2. 可见性开关默认开；关闭 = 本机不出现在他人发现列表、也不主动发现；设置持久化（`lt.lanVisible` 模式同 `lt.lastRoom`），重启保持
3. 空态/发现中/失败文案（权限拒绝、无局域网设备、AP 隔离提示降级 QR）
4. 桌面端：局域网区块显示「本地服务器连接的设备」（T08 接入），无发现能力时不出现空误导文案
5. 文档一致：ADR-0006 修订、CONTEXT.md 决策记录同步（无漂移）

## 备注
- 在线/离线边界（ADR-0009 决策 6）：信令可达时在线房间为主，局域网区块仍可显示（app 端）；离线时局域网区块为主
- 视觉上两区块需可区分（标题/来源 tag），避免与现有房间设备混淆
